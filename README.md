# Aneno One

Quick English and Simplified Chinese switching for Blender. Version **0.1.0**.

Use the right-hand Topbar button, the Aneno One tab in the 3D Viewport sidebar, or a shortcut you assign yourself. Enable or hide either entry independently. Blender remains in control of language settings, key bindings and preference saving.

- [中文使用说明](docs/usage.zh-CN.md)

Install the extension package **aneno_one-0.1.0.zip** through **Preferences → Get Extensions → menu → Install from Disk**. The source archive is intended for reviewing or building the project; use the extension package for installation.

Verified on Windows 11 with Blender 5.2.2 LTS. The manifest minimum is Blender 5.0.0; older development builds were tested on 5.0.0 and 5.1.2, but version 0.1.0 has not been tested on those versions. English-language Windows, Linux, macOS and additional display configurations remain unverified. See the user guide for known native window issues.

No default shortcut, third-party runtime dependency, additional permission, telemetry or built-in updater. Maintainer: **Aneno**.
