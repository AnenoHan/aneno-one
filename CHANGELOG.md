# Version notes / 版本说明

## 0.1.0

English and Simplified Chinese switching from the right-hand Topbar and 3D Viewport sidebar, with an operator for manual key binding. Includes independent entry controls, a module switch, read-only shortcut information, native Keymap settings access, binding help, About information and Simplified Chinese UI messages.

Blender owns the language, bindings and save policy. No shortcut is installed automatically. Existing data names are preserved. Switching to Chinese enables native Interface Translation; other translation flags retain their values.

Version 0.1.0 keeps the behavior of the release candidate. Verification targets Windows 11 / Blender 5.2.2 LTS. The manifest minimum remains 5.0.0; 5.0.0 and 5.1.2 have only historical development-build results. English-language Windows, Linux, macOS and additional display configurations are unverified. Known native Topbar blanking and historical 5.1 window issues remain disclosed in the [English guide](docs/usage.en.md).

提供右侧 Topbar、3D 视图 Sidebar 和可手动绑定的操作符，用于简体中文与英文切换。包含独立入口开关、模块开关、只读快捷键信息、原生键位映射设置入口、绑定帮助、About 信息和中文界面文案。

语言、快捷键及保存策略由 Blender 管理，不自动创建快捷键，不重命名已有数据。切到中文会开启原生“界面”翻译，其他翻译开关保持原值。

0.1.0 保持候选版功能。验证范围为 Windows 11 / Blender 5.2.2 LTS；最低版本仍为 5.0.0，5.0.0 和 5.1.2 仅有历史开发版本记录。英文 Windows、Linux、macOS 和其他显示配置未验证。原生顶栏空白及历史 5.1 窗口问题见[中文说明](docs/usage.zh-CN.md)。
