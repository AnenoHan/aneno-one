# Aneno One 0.1.0 使用说明

[English](usage.en.md) · [项目介绍](../README.md) · [版本说明](../CHANGELOG.md)

## 1. 功能与适用环境

Aneno One 提供简体中文与英文快速切换。可从右侧顶栏按钮、3D 视图侧栏或自行绑定的快捷键调用。插件设置中可分别开关两个界面入口、查看真实快捷键状态，并在 About 中查看版本。

本版本实际验证环境为 Windows 11 / Blender 5.2.2 LTS。安装清单的最低版本为 5.0.0；5.0.0 和 5.1.2 仅有历史开发版本测试记录，0.1.0 未在这两个版本重新验证。英文 Windows、Linux、macOS 和其他显示配置尚未验证。

## 2. 安装与升级

1. 准备 **aneno_one-0.1.0.zip** 安装包，不要解压。
2. 打开 Blender 的 **编辑 → 偏好设置 → 获取扩展**，从右上角菜单选择 **从磁盘安装**，选取安装包并完成安装。
3. 在 **插件** 页面确认 Aneno One 已启用，展开设置，在 About 中检查版本为 **0.1.0**。
4. 首次安装默认开启语言切换模块、Topbar 和 Sidebar。3D 视图中按 **N** 打开侧栏，选择 **Aneno One** 标签。
5. 从旧版或候选版升级时，选择原来使用的本地扩展存储库，在原位置升级，避免重复安装。不需要先卸载或重新绑定快捷键；已有语言、入口选择和手动绑定应保留。

请使用安装包完成安装，不要直接将源码归档复制到旧版 `scripts/addons` 目录。

## 3. 切换语言

| 按钮显示 | 含义 | 点击后的行为 |
|---|---|---|
| EN | 当前设置为英语 | 切换到简体中文，并开启原生“界面”翻译 |
| 中 | 当前设置为简体中文，界面翻译开启 | 切换到英文 |
| 中* | 当前设置为简体中文，界面翻译关闭 | 切换到英文 |
| AUTO | 当前语言为自动选择 | 弹出中英文选择，按 Escape 取消 |
| 其他缩写 | 当前设置为其他语言 | 弹出中英文选择，按 Escape 取消 |

按钮反映 Blender 的语言设置，不保证每一处可见文字都有翻译。AUTO 的按钮文字与实际界面语言可能不同。

切换到中文会开启原生“界面”翻译；工具提示、报告、新建数据等其他翻译开关保持原值。切换到英文时也保留这些开关。语言改变后，工具提示或新建数据名称仍可能随 Blender 的语言发生变化。已有对象和其他数据名称不会被插件重命名。

## 4. 模块和入口开关

在 **偏好设置 → 插件 → Aneno One** 中，可以分别关闭 Topbar 或 Sidebar。关闭语言切换模块会隐藏入口并禁止切换，重新开启会恢复之前选择的入口状态。

可以同时隐藏两个入口并使用自行绑定的快捷键；如果也没有可用绑定，插件会提示开启入口或设置快捷键，不会自动替你更改配置。

## 5. 手动设置快捷键

插件默认不创建快捷键。设置区只读取 Blender 当前的真实绑定，不会自动添加、覆盖或删除绑定。

1. 点击插件设置中的 **打开键位映射设置**，清空原生键位映射页面的搜索框。
2. 展开 **Window**，滚动到该类别底部，点击 **Add New / 添加新项**，然后展开新增条目。
3. 在操作符标识字段中填写 `aneno_one.language_switch`。
4. 选择希望使用的按键和修饰键，并保持条目启用。请避免与已有快捷键冲突。
5. 返回主窗口，测试中英文往返切换。第一次未建立绑定时，直接搜索插件名称可能没有结果。
6. 若关闭了自动保存偏好设置，手动保存以保留绑定。

Window 绑定可跨编辑器使用；在其他 Keymap 中建立的绑定仅在对应上下文生效。已有快捷键或模态工具可能拦截同一按键，插件不会自动解决冲突。多个绑定、禁用状态及作用范围会显示在插件设置中。

需要删除绑定时，在原生键位映射页面移除对应条目。插件会随实际状态更新显示。

## 6. 保存设置

语言、入口选择及快捷键的保存遵循 Blender 的偏好设置机制。开启自动保存时由 Blender 保存；关闭自动保存时，请从偏好设置菜单执行 **保存偏好设置**。

保存 `.blend` 文件不能代替保存偏好设置。Aneno One 不会强制保存其他全局设置，也不另存一份语言或快捷键状态。

## 7. 停用与卸载

在插件页面取消启用 Aneno One 可停用插件；通过原生扩展菜单可卸载插件。插件会清理自己注册的界面和资源，保留当前语言及用户手工创建的快捷键。

卸载后的绑定不能继续执行插件功能。如果不再需要，可在原生键位映射页面手动删除。

## 8. 已知限制与排查

1. 原生整条顶栏可能在窗口或布局变化后空白；手动最大化窗口再还原通常可以恢复。有无本插件的环境均有此现象记录，问题尚未修复。
2. Blender 5.1 的历史测试中还记录了双窗口崩溃和保存后脚本创建窗口的 Win32 1407 故障，不能据此承诺该版本任意多窗口操作均正常。
3. 已打开的旧工具提示可能保留旧语言；移开鼠标并重新悬停会重新生成提示。
4. 没有 Topbar 的最大化或全屏编辑器不会显示顶栏按钮；在可用上下文中使用 Sidebar 或手动快捷键。
5. 按钮不见时，先检查模块及对应入口开关；快捷键无效时，检查绑定启用状态、作用范围和冲突。

反馈问题时，请提供插件版本、Blender 版本、操作系统、复现步骤、预期与实际结果。截图和日志请先移除个人信息、文件路径以及无关项目内容。
